# Tour Sim v2 Test

Test build of **Tour Sim v2.1**. Game code is coming soon; this page is a placeholder.

## What's coming in v2.1
- **Customization menu** on the opening screen: ball color (white, yellow, orange, red, blue, pink, black), ball trail (on/off, length and color), and a hole explosion effect (particles and sound).
- **Six new courses**, each compared against real-life photos: Lulu Country Club, Five Ponds Golf Course, Lake Charles Country Club, TPC Sawgrass (Stadium Course), St Andrews (Old Course) and Bethpage Black.
- **Tournament mode:** a 4-day, 72-hole event on any course against computer golfers, with standings after each round and a champion screen.
- **Password gate** on first open.
- Existing courses, saves, records and settings carry over.

Final release stays at [tour-sim-final](https://github.com/jamesgregory5-svg/tour-sim-final) until v2 is approved.
